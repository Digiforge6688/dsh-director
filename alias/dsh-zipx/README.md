# dsh-zipx

Discovery alias for **DSH Director / DSH导演**. Installing this package pulls
`@zipx/dsh-plugin` and applies the same DSH bundle layer, so the runtime implementation stays in
one place.

It exists so people who search for a `dsh-*` package name can find the same plugin; the canonical
package and market title are **DSH导演 / DSH Director** (`@zipx/dsh-plugin`).

ZipX account: <https://www.zipx.ai> (global) · <https://www.zipx.vip> (China).

```powershell
dsh plugin --profile web add dsh-zipx@0.6.0
```
