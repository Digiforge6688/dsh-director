# dsh-zipx

Discovery alias for **DSH Director / DSH导演**. Installing this package pulls
`dsh-director` and applies the same DSH bundle layer, so the runtime implementation stays in
one place.

It exists so people who search for a `dsh-*` package name can find the same plugin; the canonical
package and market title are **DSH导演 / DSH Director** (`dsh-director`).

ZipX account: <https://www.zipx.ai> (global) · <https://www.zipx.vip> (China).

```powershell
dsh plugin --profile web add dsh-zipx@1.0.1
```

See the canonical README for connection, cards, approval, jobs, workbench and limits.
